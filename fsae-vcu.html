Description

Overview

The Vehicle Control Unit (VCU) is the brain of the 26E car. Emphasis was placed on rules compliance and reliability, hence an incredibly simple yet tested design. The core code operates in a simple while loop, ensuring easy debugging and maintenance.

Key Features

  • FSAE-compliant Accelerator Pedal Position Sensor (APPS) and Brake System Evaluation (BSE) plausibility checks
  • Gradient-based accelerator position calculations via ADC inputs
  • Real-time torque command generation and CAN bus transmission at 500 kilobaud
  • Ready to Move (RTM) system implementation for driver safety
  • Motor controller integration with Cascadia PM100DX inverter and Emrax 228 motor
  • 100 millisecond rule compliance for safety-critical operations
  • Hardware abstraction via Prototype VCU hat for simplified integration, later replaced with the Front-of-Car Power Distribution Board
  • Integrated convenient pedal recalibration function for easy maintenance
  • Edited hardware option bytes to ensure VCU automatic startup
